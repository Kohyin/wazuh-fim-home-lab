#### 🛡️ SOC Lab Project 01: File Integrity Monitoring with Wazuh on Windows

**Problem Solved**
Attackers and malware often modify critical system files to persist or hide. This project shows how a SIEM can detect those changes: I deployed a Wazuh manager, connected a Windows 11 agent, and monitored `C:\Windows\System32` to catch unauthorized file creation.
